### Как включить прокси

1. Нажмите на иконку расширения в панели Chrome
2. Нажмите **"Включить прокси"**
3. Выберите страну (или оставьте "Лучший")
4. Прокси активирован — ваш IP изменен

### Как выбрать страну

1. Нажмите на иконку расширения
2. Раскройте список **"Выбор страны"**
3. Выберите страну (Россия, США, Германия и др.)
4. Нажмите **"Применить"**
5. Расширение автоматически выберет прокси из выбранной страны

### Как настроить авто ротацию IP

1. Нажмите на иконку расширения
2. Нажмите **"Настройки"**
3. Включите **"Автоматическая ротация"**
4. Выберите интервал (5, 10, 15, 30 минут)
5. Нажмите **"Сохранить"**
6. IP будет меняться автоматически

### Как добавить сайты в белый список

1. Нажмите на иконку расширения
2. Нажмите **"Настройки"**
3. Найдите раздел **"Белый список"**
4. Добавьте сайты, которые не нужно пропускать через прокси
5. Например: `yandex.ru`, `vk.com`
6. Нажмите **"Сохранить"**

### Как обновить список прокси

1. Нажмите на иконку расширения
2. Нажмите **"Обновить прокси"**
3. Расширение загрузит новый список
4. Будет показано количество новых прокси
5. Обновление происходит автоматически раз в день
